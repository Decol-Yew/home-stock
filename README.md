# home-stock

Ultima Online の **自宅在庫（秘薬・矢・空き瓶・白紙巻物など）を、最後に確認した時点の
スナップショットとして表示する**ツールです。買い出し前にこれを見て、その場のNPC在庫と
相談しながら「今日どれを重点的に補充するか」を判断します。買うたびに数字を更新する運用は
しません。**補充して帰宅したときだけ**在庫数を書き換えます。

`index.html` は単体で完結しており、GitHub Pages でもローカルの `file://` でも動きます。

## 使い方

1. 出発前にこのページを開き、各品目の在庫数を確認する
2. **「下限割れのみ」**を押すと、下限を下回っている品目(＝補充候補)だけが残る
3. 買い出しへ。NPCの在庫切れもあるので「買う数」は固定しない
4. 補充して帰宅したら、各カードの **−10 / −1 / ＋1 / ＋10** か数値を直接入力して在庫数を更新
   （更新すると「最終確認日」が自動で今日になります）

## できること

- 品目カードで在庫数を **その場で増減・直接入力**（分類＝秘薬／その他で色分け）
- **下限割れ**の品目はカードを赤く強調し、「補充したい」バッジを表示
- **下限割れのみ表示**トグル／分類フィルタ
- 品目の **追加・編集・削除**（名前・和名・分類・下限・在庫・メモ）
- **最終確認日**の表示・手動設定・「今日に更新」
- **JSON 書出 / 読込**：バックアップ・端末間共有・バージョン管理用
- **印刷**：操作ボタンを隠してカード一覧だけを紙／PDF に
- **既定に戻す**：初期データ(`stock.default.json`)に戻す

## データの流れ（端末間で同じ内容を表示）

- ページを開くと、リポジトリの **`data/stock.json`** を読み込んで表示します。
  → GitHub Pages で公開すれば、**どの端末で開いても同じ最新版**が出ます。
- ブラウザ上での編集は、その端末の **下書き（localStorage）** に保存されます（他端末には出ません）。
  上部のステータスバーが「未コミットの下書きを表示中」に変わります。
- 編集を**全端末へ反映**するには、
  1. 「**JSON 書出**」で `stock.json` をダウンロード
  2. それを `data/stock.json` として**コミット**（push）
  3. 各端末で再読込（または「**リポジトリ最新**」ボタン）
- 「**リポジトリ最新**」… 下書きを破棄してリポジトリの最新を取得
- 「**既定に戻す**」… `data/stock.default.json` に戻す

ローカルで `file://` で開いた場合はリポジトリを読めないため、埋め込みの初期データ＋その端末の
下書きで動きます（オフライン表示）。

## データファイル

- `data/stock.json` … ページが実際に読み込む**現行データ**。編集はここにコミットして更新する
- `data/stock.default.json` … **初期データ（種）**。「既定に戻す」の戻り先

各品目の形式:

```json
{ "name": "Black Pearl", "jp": "黒真珠", "category": "reagent", "count": 120, "min": 100, "note": "" }
```

- `category` … `reagent`（秘薬） / `other`（その他）
- `count` … 前回確認した在庫数
- `min` … 下限（これを下回ると「補充したい」）

## GitHub Pages で公開する（端末間同期のため）

1. リポジトリを **public** にする（この構成では公開済み）
2. Settings → Pages → Source をブランチ `main` / `/ (root)` に設定
3. 数分後 `https://decol-yew.github.io/home-stock/` で開ける

ホストしない場合も `index.html` をローカルで開けば単体で使えます（オフライン表示）。
